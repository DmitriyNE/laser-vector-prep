# Known defects

Open defects first, then fixed ones. One line each; details go in the log or an issue.

| ID | Status | Area | Description | Found | Fixed |
|---|---|---|---|---|---|
| DEF-20 | fixed | geometry | Offsets broke on boundaries drawn with micron-long chords (a curve approximated finely, or two approximations merged into a zig-zag): in millimetres such segments fall below the offset kernel's fixed parallel test, so it took them for lines folded back on themselves. Contour fill of an Altium board shed tens of thousands of sub-micron loops, missed 20% of the copper, and its gap fill ran out of memory (17 GB). Offsets now run in micrometres; contour fill also drops ring pieces smaller than a tenth of the pitch, and gap fill grows its levels coarsely where microscopic loops would blow up. Its coverage audit then took 22 s, nearly all of it winding numbers recomputed over every segment of large loops; they are now taken through segment indexes (4.4 s). Found with a customer's IPC-2581 file. | 2026-10-26 | 2026-10-26 |
| DEF-19 | fixed | import | The IPC-2581 reader skipped features grouped in a `UserSpecial` directly inside `Features` and standard primitives placed directly, and read lines whose `LineDesc` is inline (not a reference) as zero-width centrelines. Altium writes both, so most traces of its exports were missing or unusable in a region layer. Found with a customer's IPC-2581 file. | 2026-10-26 | 2026-10-26 |
| DEF-18 | fixed | ui | Mapping an imported layer onto a slot wrote a rule matching its declared function even when other layers share it (IPC-2581 inner layers are all `SIGNAL,INTERNAL`), so the slot became ambiguous and could not be mapped to either. The rule now uses the function only when it picks that one layer; the ambiguity message names the candidates. Found by the owner. | 2026-10-26 | 2026-10-26 |
| DEF-17 | fixed | tests | A failing native test could print no message at all: gap fill silenced the panic hook around each Voronoi build by swapping the process-wide hook, and since D35 two threads could restore each other's hooks and leave the silent one in place. The hook is now installed once and stays silent only on the thread building a diagram. Wasm (panic = abort) never swapped hooks. Found when a test failure printed nothing. | 2026-10-26 | 2026-10-26 |
| DEF-16 | fixed | geometry | The coverage audit missed the centreline of every trace whose half-width equals a ring's depth (a 0.3 mm trace at the LDI preset's 0.02 mm pitch, rings at 0.01, 0.03 … 0.15 mm): that ring runs into the trace and back along its centreline (a zero-width bridge), and stroking a closed path as the ring between the offsets of its area loses the bridge, so the audit reported a 0.09 mm² stripe missed. The stroke now splits a loop where it runs back along itself and strokes the bridge as an open path; contour fill emits the bridge once, as an open path, instead of marking it twice. Found while measuring DEF-15. | 2026-10-26 | 2026-10-26 |
| DEF-15 | fixed | patterns | Gap fill only filled the core past an island's deepest ring, so necks, fingers and traces that run out of rings before the rest of their island kept an unmarked core up to a pitch wide: 1.2% of the copper of the LDI preset's 2×2 test panel (gap fill drew nothing). Cores are now found at every ring level; the panel's missed area fell to 0.04%. Found by scoping the contour fill generalisation. | 2026-10-26 | 2026-10-26 |
| DEF-14 | fixed | geometry | Cancelling during a coverage audit could take seconds (18 s in a debug build): stroking the paths and clustering the loops before the boolean never checked for cancellation, and clustering was quadratic in nested fill rings, since every ring's box overlaps every other's. Clustering now skips boxes inside an already processed one (same clusters, one query per island) and both check for cancellation. Found by the Firefox cancel test on CI after D36 made the fill fast enough to reach the audit before the cancel. | 2026-10-25 | 2026-10-25 |
| DEF-13 | fixed | wasm | In the browser, more threads made evaluation slower: an 8×8 panel took 53 s with ten threads and 10 s with two, because std's wasm allocator serialises every allocation on a spin lock that starves under contention. The wasm build now has its own allocator (D36): 3.3 s with ten threads. Found by timing D35 in Chrome. | 2026-10-25 | 2026-10-25 |
| DEF-12 | fixed | geometry | Near-coincident edges and arcs whose vertices did not line up could leave a boolean's boundary chain open: that part of the composite was dropped with a warning (D30). Vertex snapping also took the first vertex in range instead of the nearest, which could leave a sliver. Now resolved exactly where possible, else by a robust polygon boolean (D34). Found by fuzzing. | 2026-10-25 | 2026-10-25 |
| DEF-11 | fixed | geometry | A PDF whose transforms produced non-finite coordinates crashed a clip boolean (NaN in the kernel's spatial index). Booleans now refuse non-finite loops (D30). Found by fuzzing. | 2026-10-25 | 2026-10-25 |
| DEF-10 | fixed | geometry | Compositing was quadratic in loops stacked in one place (a step-and-repeat with zero step flashed every pad hundreds of times): 11 s for a 1 KB Gerber. Exact duplicates are now merged with a count (D30). Found by fuzzing. | 2026-10-25 | 2026-10-25 |
| DEF-9 | fixed | readers | Small files could expand without bound: block arrays of block arrays (DXF), step-and-repeat counts (Gerber), recursive references (GDSII), forms invoking forms or themselves (PDF), dictionary primitives placed by many pads (IPC-2581). Now bounded by the import work budget (D31); self-invoking forms are skipped. Found by fuzzing. | 2026-10-25 | 2026-10-25 |
