# Engineering notes

Working notes for people building the thing. Product documentation lives one level up
in `docs/`; this folder is only about the engineering flow.

- [`log.md`](log.md) — dated engineering log: what was done, what was learned
- [`todo.md`](todo.md) — backlog by milestone, plus open questions
- [`decisions.md`](decisions.md) — numbered decisions with rationale (ADR-lite)
- [`defects.md`](defects.md) — known defects and their status
