# Regression fixtures

Synthetic inputs generated by `crates/lvp-fixtures`: DXF from the core's own writer, Gerber
and SVG from small emitters in the fixtures crate, PDF via lopdf (all independent of the
core's readers).
Regenerate with `just fixtures`; never edit the files by hand — a test in `just test`
fails when they differ from the generator's output.

`manifest.json` describes every fixture: file, units, per-layer entity counts, computed
bounds in millimetres, and `expect` values a correct pipeline must observe. Tests should
read expectations from the manifest rather than hard-coding numbers.

| Fixture | Exercises |
|---|---|
| `dxf/board-islands.dxf` | Board outline on `ROUTE_TOOL_PATH` (25.0 × 11.3 mm rounded rectangle) and copper on `TOP_LAYER`: round and rectangular pads, a pad-joining trace, an obround slot, a free zigzag trace, an annulus. 10 islands, 1 hole. Stand-in for the historical pogo board. |
| `dxf/nested-holes.dxf` | Square → square hole → circular island → square hole (depth 4), plus a disjoint triangle and circle. Hole topology and domain subtraction. |
| `dxf/open-linework.dxf` | Lines, an arc, an open polyline and an almost-closed square (0.5 mm gap) on `MARK`; one closed rectangle on `FILL`. Open linework must never become a region. |
| `dxf/units-inch.dxf` | `$INSUNITS = 1`: a 1 × 0.5 in rectangle and a 0.1 in circle; must read as 25.4 × 12.7 mm. |
| `dxf/blocks-insert.dxf` | One block (circle + square) inserted four times with translation, 45° rotation, 2× scale, and 0.5× scale with 90° rotation. |
| `gerber/board-F_Cu.gbr` | The board fixture's copper as Gerber X2 (`Copper,L1,Top`): C/R/O flashes, a C aperture with a hole (annulus), traces as draws. Must read as the same 10 islands / 1 hole as the DXF. |
| `gerber/board-Edge_Cuts.gbr` | The board outline (`Profile,NP`) drawn as a closed 0.05 mm contour with quarter-circle corners. Readers must return one closed path. |
| `svg/marking.svg` | Inkscape-style layers `MARK` (stroked line, polyline, quadratic Bézier, rotated group), `FILL` (Bézier circle, even-odd ring, scaled `use` pads) and `CLIPPED` (rect cut by a clipPath), 60 × 20 mm with a 1:1 viewBox. Binds the general-marking preset directly. |
| `pdf/features.pdf` | One page: an optional-content layer with a stroked square, a red Bézier circle, a black even-odd ring, green pads from a scaled form XObject, a grey fill cut by a clipping path, plus text and an image that must be diagnosed. Layers come back as the OCG name or `#rrggbb`. |
| `gerber/features.gbr` | One of everything: region with clear/dark compositing, step-and-repeat, thermal and outline macros with variables, obround and polygon apertures, an arc draw, an aperture block flashed rotated. Disjoint features, so the manifest's area is the sum of analytic areas. |

DXF files are R2000 (AC1015) with handles and a full table skeleton; `ezdxf audit`
reports no errors and its independent reading matches the manifest. Gerber files use
`FSLAX46Y46`, millimetres and X2 attributes.

Known-good export outputs (PDF/SVG/DXF) will be added here once the exporters exist.
Fixtures are test data only and are never bundled into the shipped site.
